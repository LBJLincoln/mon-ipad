Generate a Nano Banana video brief for a product demo.

Arguments: $ARGUMENTS (sector or product name)

Steps:
1. Read design brief from `directives/website-design-briefs.md`
2. Read the sector data from `technicals/data/sector-datasets.md` if applicable
3. Define the video concept:
   - Target persona (from design brief)
   - Pain point to address
   - Product solution demo
   - Call to action
4. Write a 5-scene storyboard:
   - Scene 1: Pain point visualization (problem the persona faces daily)
   - Scene 2: Discovery (persona finds the product)
   - Scene 3: Demo (show the chatbot/dashboard in action with real data)
   - Scene 4: Results (metrics, ROI, time saved)
   - Scene 5: CTA (clear next step with urgency)
5. For each scene provide:
   - Nano Banana text prompt (detailed, cinematic)
   - Duration (3-5 seconds per scene)
   - Voiceover script (French, professional tone)
   - Background music mood
6. Output: Complete video brief ready for Nano Banana API or manual generation
