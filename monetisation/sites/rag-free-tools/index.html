    Pipeline Health Checker

    Click each item to mark as passing or failing. Based on the 79+ production issues we've diagnosed.

    • Embedding dimensions match index dimensions

      Mismatch causes silent 0-result queries. Check model output dim vs index config.

      FIX: Verify with a test query. If Pinecone returns 0 matches on known docs, dimension mismatch is #1 cause. Rebuild index with correct dimensions.

    • Vector DB returns relevant results for test queries

      Run 3-5 known queries and verify top-5 results contain the expected document.

      FIX: Check namespace/index targeting. Pinecone silently returns empty if namespace is wrong. Verify with the exact index stats API.

    • Chunking preserves context boundaries

      Chunks shouldn't split mid-sentence or cut off table rows.

      FIX: Use semantic chunking or recursive character splitting with overlap. Fixed-size chunks lose 15-20% accuracy on structured data.

    • LLM prompt includes retrieved context

      Sounds obvious, but empty context strings are the #2 most common bug.

      FIX: Log the full prompt sent to the LLM. If context is empty or "undefined", trace back to the retrieval step. Check for async timing issues.

    • LLM temperature is set appropriately

      RAG generation should use temp 0-0.3. Higher causes hallucination.

      FIX: Set temperature to 0.1 for factual QA. Only increase for creative tasks. Check if your framework has a default temp that overrides yours.

    • System prompt instructs grounding in context

      Without "only answer from the provided context", LLMs hallucinate 40%+ of the time.

      FIX: Add explicit grounding instruction: "Answer ONLY based on the provided context. If the answer is not in the context, say you don't know."

    • API endpoints respond within 5 seconds

      Timeout chains: if embedding API is slow, everything downstream fails.

      FIX: Add timeout monitoring to each API call. Self-hosted embeddings eliminate third-party latency. Our bundle includes a free HF Space setup.

    • Error handling on empty retrieval results

      What happens when vector search returns 0 results? The system should gracefully handle it.

      FIX: Add a fallback path: try broader search, or return "I don't have information on that topic" instead of passing empty context to LLM.

    • Database connections use correct ports/pooling

      Supabase port 5432 vs 6543 can silently drop inserts. Neo4j connections time out without keep-alive.

      FIX: Supabase: use port 5432 (session pooler), NOT 6543 (transaction pooler). Neo4j: set connection timeout to 30s+ and enable keep-alive.

    • Automated evaluation pipeline exists

      Without automated eval, you can't measure improvements or catch regressions.

      FIX: Implement LLM-as-judge evaluation with at least 50 golden questions. Our Eval Framework product includes scripts for 10K+ question parallel evaluation.
