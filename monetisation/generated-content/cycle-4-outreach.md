**Title:** The RAG debugging flowchart we wish we had from day 1

```
Built this after debugging 79+ failures across 4 production RAG pipelines.

The approach: when you get a wrong answer, don't tune prompts. Trace backwards.

1. Check generation input — is the right context in the prompt?
   → No? Retrieval problem. Go to step 2.
   → Yes? Generation problem. Check prompt template, max tokens, temperature.

2. Check retrieved documents — are the right docs in the top-K?
   → No? Embedding/indexing problem. Go to step 3.
   → Yes, but wrong order? Reranking problem. Check score calibration.

3. Check the index — is the source document chunked correctly?
   → Wrong chunks? Chunking problem. Check strategy and overlap.
   → Right chunks but not retrieved? Embedding mismatch. Check model and query transformation.

This simple trace resolved 80% of our issues without touching the LLM.
```
