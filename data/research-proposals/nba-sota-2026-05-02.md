### Actionable Techniques from Literature

#### 1. Monte Carlo Dropout (Uncertainty-Aware, MDPI Jan 2026)
- **What**: Add MC dropout to ensemble models to get calibrated uncertainty estimates
- **Brier impact**: 0.20 claimed on 2024 data (XGBoost baseline at same level)
- **Feasibility for islands**: Tree-based islands cannot directly use dropout, but **calibration post-processing** (Platt/isotonic) is equivalent and already in use
- **Actionable**: Ensure isotonic calibration is applied in island eval — S22's 0.22027 is pre-calibration; TabICL calibrated score was 0.22054. May want calibrated Brier as primary metric.

#### 2. Rolling-Form Shot Chart Embeddings (Uncertainty-Aware, MDPI Jan 2026)
- **What**: Spatial shot chart data as rolling-form feature input
- **Brier impact**: Helps capture team-level spatial performance trends
- **Feasibility**: Shot chart data available via NBA API; would require cat 55+ in engine.py
- **Actionable**: Add `SHOT_CHART_ROLLING` category to engine.py (propel to v3.2) with 20-30 features: zone_eff_home_3g, zone_eff_away_3g, 3pt_attempt_rate_delta, paint_touch_rate_delta, etc.

#### 3. Stacked Ensemble with Cross-Validation (Nature Sci Reports 2025)
- **What**: L1 models predict on OOF data → L2 meta-learner
- **Status**: Already removed from islands (CPU-only, Rule #8). Valid on Kaggle/Colab.
- **Actionable**: Kaggle Karpathy loop should test stacking with TabICL as L2 on CPU tree L1 outputs.

#### 4. XGBoost with SHAP-guided Feature Selection (PMC 2024)
- **What**: Use SHAP values to prune features below importance threshold
- **Feasibility**: Can run on island population during GA selection phase
- **Actionable**: Add SHAP importance gate to `features/engine.py` GA eval: features with mean |SHAP| < 0.001 across 5-game window get weight-penalized in mutation.
