# NBA SOTA Research Proposals — 2026-05-02

> Brain cycle 2026-05-02 12:00Z. Sources: arXiv search, paperswithcode.

## Key 2025-2026 Papers Found

### 1. Long-Sequence LSTM (arXiv 2512.08591, Dec 2025)
- 8-season LSTM, 9,840 games, **72.35% accuracy**, 73.15% precision, 76.13% AUC-ROC
- Key innovation: captures temporal dependencies across seasons (vs our per-season features)
- Gap: no Brier score reported. 72.35% accuracy maps roughly to Brier ~0.22-0.23.
- **Proposal**: Add cross-season rolling context features to engine.py — rolling-season opponent strength, multi-year team chemistry signals

### 2. MOVDA Enhanced ELO (arXiv 2506.00348, Jun 2025)
- Margin-of-victory deviation analysis, 13,619 games (2013-2023)
- **+1.54% Brier improvement** over TrueSkill, 13.5% faster ELO convergence
- Formula: `expected_margin = home_elo - away_elo` → `mov_deviation = actual_margin - expected_margin`
- **Proposal**: Add `rolling_10g_mov_deviation` features to engine.py. We have ELO features already; MOV deviation is additive, zero training-data cost.
- Estimated impact: ~0.001-0.003 Brier improvement

### 3. CausalTraj Multi-Agent Tracking (arXiv 2511.18248, Nov 2025)
- NBA SportVU player tracking, joint probability forecasting
- Requires tracking data not in our dataset — long-term exploration only

### 4. Aging/Career Decline LSTM (arXiv 2509.25858, Sep 2025)
- Autoencoder + K-means + LSTM for aging-adjusted performance prediction
- **Proposal**: Add player-age-adjusted rolling stats as engine features (age × form interaction)
