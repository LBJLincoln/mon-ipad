## Key Findings from 2025-2026 Literature

### CNN achieves Brier 0.221 (MDPI Computation 2026)
Paper: "Machine Learning for Basketball Game Outcomes: NBA and WNBA Leagues"
- CNN model achieved **Brier 0.221** — best single-model result in published literature
- Architecture: temporal 1D convolutions over past N game sequences
- Top features: home/away status, team Elo at 5-game intervals, current form
- Outperforms XGBoost, RF, LR, SVM on same dataset
- **Gap to our fleet best:** 0.22012 (S15) vs 0.221 = 0.00088 — we are nearly at published SOTA

### Stacked Ensemble (Scientific Reports 2025)
Paper: "Stacked ensemble model for NBA game outcome prediction analysis"
- Multi-model stacking with meta-learner improves 0.003-0.005 Brier over best base model
- Key: base learner diversity + out-of-fold meta-training to prevent leakage
- Architecture: tree ensembles (RF/XGB/LGB) as base + logistic meta-learner

### XGBoost + SHAP Feature Pruning (PMC 2025)
Paper: "Integration of ML XGBoost and SHAP models for NBA game outcome prediction"
- SHAP-based feature pruning: remove bottom-50% by absolute SHAP value
- Reduced feature set improves generalization (less overfitting)
- Applied to NBA: 1200-feature pool → 400 high-quality features, Brier improved
