## Actionable Proposals (Priority Order)

### PROPOSAL A — Logistic Meta-Learner (HIGH PRIORITY)
- **What**: Add logistic regression layer on top of tree model outputs
- **How**: In S17/S18 ensemble, collect OOF predictions from each model → train LR meta-learner → isotonic calibration
- **Expected gain**: 0.001-0.003 Brier reduction (could push below 0.22085)
- **Cost**: Low — runs on CPU, 1 extra training step per generation
- **Implementation**: Add to features/engine.py as post-processing step

### PROPOSAL B — AutoGluon Trial on Kaggle
- **What**: Run AutoGluon TabularPredictor on our 9551-game dataset
- **How**: `AutoGluon.fit(label='home_win', presets='best_quality', time_limit=3600)`
- **Expected**: May beat manual XGBoost ensembles with zero tuning
- **Cost**: Kaggle P100 9h session (1 run)

### PROPOSAL C — Isotonic Calibration Post-Processing (LOW RISK)
- **What**: Apply `sklearn.isotonic.IsotonicRegression` on hold-out set after GA training
- **How**: Already deployed in S20 (isotonic_cpcv) — port to S17/S18
- **Expected gain**: 0.0005-0.001 Brier (pure calibration improvement)
- **Cost**: Trivial — 2 lines of code added to evaluation step

### PROPOSAL D — MC Dropout via GPU Burst
- **What**: LSTM+MC dropout for playoff-aware sequence modeling
- **How**: Deploy via Modal A10G burst — 15 runs x 30 dropout masks
- **Expected**: SOTA-level but GPU-only, not deployable on CPU islands
- **Cost**: Modal budget (free A10G tier)
