## New Findings (not in fire-75)

### 1. MambaNet — SSM Hybrid for NBA Playoffs (Springer Nature 2024/2025)
**Paper**: "MambaNet: A Hybrid Neural Network for Predicting the NBA Playoffs"
**URL**: https://link.springer.com/article/10.1007/s42979-024-02977-0

**Key result**: Hybrid Mamba (state-space model) + traditional ML layers achieves **AUC 0.72–0.82** on NBA playoffs, beating best-performing baseline models by a "considerable margin".
- Mamba replaces Transformer's O(n²) attention with O(n) recurrence — more efficient on long game sequences
- Particularly strong on playoff sequences where historical trajectory matters more
- **Actionable**: Mamba architecture for sequential feature extraction (pre-GA embedding) before feeding to island XGB/ET
- CPU-feasible small Mamba (< 1M params) for embedding layer

### 2. Roster-Conditioned Temporal Transformer (~25M params)
**Source**: SportBot AI 2026 benchmark summary
**URL**: https://www.sportbotai.com/blog/ai-basketball-prediction-tool-2026-1773957777133

**Key result**: Processes each team's full season history with **player-level attention**, capturing game-to-game dynamics and roster changes. Achieves 75–80% accuracy on regular-season outcomes.
- Architecture: roster embeddings + temporal attention + game-context MLP
- Advantage: captures injury/rotation impact dynamically (our engine has player props but not sequence)
- **Actionable**: Generate roster-state features (player availability index, rolling lineup continuity score) via features/engine.py — no GPU needed for feature generation

### 3. NCAA Deep Learning Transfer (arXiv 2508.02725)
**URL**: https://arxiv.org/pdf/2508.02725

- LSTM outperforms Transformer on shorter basketball sequences (< 82 games)
- Transfer learning from NCAA to NBA validated — shared court dynamics
- **Actionable**: LSTM-generated sequence embeddings as additional feature candidates for GA (already noted in fire-75 for TabICL; now confirmed portable to tree-based models)

### 4. 2026 Benchmark Consensus: 75-80% accuracy, 50+ variables
- Multiple 2026 sources converge on 75–80% regular-season accuracy with 50+ features
- Our islands use 44–75 features (in range) and achieve ~67% accuracy (Brier 0.22 ≈ 65–68% calibrated)
- Gap to 75–80%: likely from richer sequential/roster features, not just model type
