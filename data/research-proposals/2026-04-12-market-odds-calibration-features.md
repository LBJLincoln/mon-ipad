## Finding

Bookmaker odds contain systematic miscalibration:
- Favorites are **overpriced** (empirical win rates below implied probability)
- Underdogs are **underpriced** (empirical win rates above implied probability)
- This bias is measurable and predictable — tree models can learn to exploit it

The market overround (vig) ranges from 3-7%. Removing vig and using calibrated implied probabilities as features provides direct signal about "public opinion vs. true probability."

## Proposed Features (add to features/engine.py)

```python
# ===== MARKET IMPLIED PROBABILITY FEATURES =====
# Cat: market_calibration (new category)

def _add_market_calibration_features(self, home_ml, away_ml, spread=None):
    """
    Convert moneyline odds to implied probabilities and add calibration features.
    Sources: The-odds-api.com (free tier: 500 req/month)
    """
    features = {}
    
    if home_ml and away_ml:
        # American odds to decimal
        home_dec = (100 / abs(home_ml) + 1) if home_ml < 0 else (home_ml / 100 + 1)
        away_dec = (100 / abs(away_ml) + 1) if away_ml < 0 else (away_ml / 100 + 1)
        
        # Raw implied probabilities (pre-vig removal)
        home_raw = 1 / home_dec
        away_raw = 1 / away_dec
        overround = home_raw + away_raw  # should be >1.0 (e.g. 1.05)
        
        # Vig-normalized (Shin method or additive normalization)
        home_implied = home_raw / overround
        away_implied = away_raw / overround
        
        features['market_home_implied_prob'] = home_implied
        features['market_away_implied_prob'] = away_implied
        features['market_overround'] = overround
        features['market_home_favorite'] = 1 if home_implied > 0.5 else 0
        features['market_implied_margin'] = home_implied - away_implied
        
        # Historical calibration error for similar odds ranges
        # Bucket: <40%, 40-50%, >50% favorite
        bucket = int(home_implied * 10) / 10  # e.g. 0.6, 0.7
        features['market_favorite_bucket'] = bucket
        
        # Underdog value signal: implied prob in [0.35, 0.48] historically beats market
        features['market_underdog_value_signal'] = 1 if 0.35 <= home_implied <= 0.48 else 0
    
    if spread:
        # Spread implied: ~52.4% break-even at -110
        spread_magnitude = abs(spread)
        features['market_spread_magnitude'] = spread_magnitude
        features['market_large_spread'] = 1 if spread_magnitude >= 8 else 0
    
    return features
```
