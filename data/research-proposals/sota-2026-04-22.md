## Actionable Proposals

### PROPOSAL-A: Isotonic Calibration Post-Processing (HIGH PRIORITY)
**Rationale**: Logistic regression achieves Brier 0.199 via calibration. Our XGBoost/LightGBM outputs are already decent but uncalibrated.
**Action**: In `features/engine.py` + island spaces, add Platt scaling / isotonic calibration layer after tree ensemble predictions.
**Expected gain**: ~0.003-0.005 Brier improvement (literature suggests calibration alone can close 30% of gap to SOTA).
**Complexity**: Low — sklearn CalibratedClassifierCV wrapper.

### PROPOSAL-B: Venn-Abers Calibration Extension (MEDIUM)
**Rationale**: S22 uses venn_abers_fusion and achieved 0.22073 historical best — already best on fleet. Paper confirms calibration is key.
**Action**: Port S22's venn_abers_fusion to S17 and S18 as well. Multi-calibration ensemble.
**Expected gain**: 0.001-0.003 Brier on non-venn-abers islands.

### PROPOSAL-C: Stacked Meta-Learner with Logistic Regression
**Rationale**: LogReg achieves 0.199 Brier. Could be the meta-learner on top of tree ensemble base predictions.
**Action**: Add logistic regression as level-2 stacker using tree ensemble raw predictions as features.
**Complexity**: Medium — adds training complexity, but GPU burst handles it.

### PROPOSAL-D: Rolling 4-Factor Model Features
**Rationale**: Apr 2026 paper identifies eFG%, TOV%, ORB%, FT Rate as top predictors. Compare against our v3.1 feature engine.
**Action**: Audit `features/engine.py` for these 4 factors across multiple rolling windows (3/5/10/15 games). Ensure GA selects them.
**Expected gain**: Marginal (we likely already have these), but validation is worthwhile.

## Priority Recommendation
**IMPLEMENT FIRST**: PROPOSAL-A (isotonic calibration) — highest expected Brier reduction with minimal code change. CalibratedClassifierCV wraps any sklearn-compatible model in 3 lines.
