- Approach: Stacking with a meta-learner
- Relevance: Our GA already explores ensembles; TabICL (Colab best 0.21514) is a neural stacker

### XGBoost + SHAP (PMC, 2024)
- Paper: "Integration of machine learning XGBoost and SHAP models for NBA game outcome prediction"
- Key technique: SHAP values for feature importance — prunes irrelevant features
- **Actionable:** Use SHAP to audit the 61-feature set on S13. May find 10-20 features to eliminate.
- Expected Brier delta: -0.002 to -0.005 from cleaner feature set

### CNN Model (best published Brier 0.221)

- Our extra_trees at 0.2209 matches this WITHOUT neural networks
- TabICL at 0.21514 (Colab) still holds best known

### Bayesian Playoff Model (Medium, Dec 2025)
- Bayesian priors on team strength + posterior updates per game
- Could complement GA by providing calibration features (Bayesian win probability as input feature)

### XGBoost + Game Momentum (Preprints.org, Apr 2026)
- Uses 2023-24 and 2024-25 seasons, game logs + player stats + momentum indicators
- Momentum features: last-N-game rolling windows — already partially in our feature engine v3.1
