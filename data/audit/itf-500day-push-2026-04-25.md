## SECOND bottleneck: BP truthy-string bug — 2026-04-25T11:50Z

**Diagnostic:** post-MAX_OPEN raise, 72/85 decisions reverted to `broker_skip_bp_starved` ("bp=0.00 < min=100"). Alpaca actually had `buying_power: '9630.94'` but `daytrading_buying_power: '0'`. Python:
```python
'0' or '9630.94'  # returns '0'  — non-empty string is truthy!
float('0') = 0.0
```

**Fix shipped:**
```python
try: dt_bp = float(j.get("daytrading_buying_power") or 0)
except: dt_bp = 0.0
try: bp = float(j.get("buying_power") or 0)
except: bp = 0.0
return max(dt_bp, bp)
```
- HF commit: `ec2ec3c640306dacba2b34859e3808a275b1a8d6`
