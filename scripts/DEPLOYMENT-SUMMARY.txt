  ✓ POST with test question to each webhook
  ✓ Verify HTTP 200 + non-empty response
  ✓ Classify as: OK / EMPTY / ERROR / TIMEOUT

Phase 4: Generate report (10s)

  ✓ Calculate success rate per pipeline
  ✓ Identify failed spaces/webhooks

┌───────────────────────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING                                                               │
└───────────────────────────────────────────────────────────────────────────────┘

Problem: "Dependencies missing"
Solution: sudo apt-get install -y python3 curl jq

Problem: "Environment variables missing"
Solution: Edit .env.local and add required variables
         (script will tell you which ones are missing)

Problem: "Spaces unreachable (TIMEOUT)"
Solution: Normal if spaces are sleeping. They will wake up automatically.
         Wait 30-60 seconds and retry.

Problem: "Webhooks return EMPTY"
Solution: Check credentials in .env.local
         Verify workflows are active in n8n interface
         Check execution logs in n8n

Problem: "Login failed"
Solution: Verify n8n credentials in the Python scripts
         Default: ci@nomos.ai / CI-Nomos-2026!
